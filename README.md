# Canapéro

Canapéro transforme ton Android TV en plateau de jeux de soirée. Installe l'appli sur la TV, scanne le QR code avec ton téléphone… et c'est parti ! Pas de manette à acheter, pas d'appli à installer sur les téléphones : ils deviennent des manettes directement dans le navigateur.
